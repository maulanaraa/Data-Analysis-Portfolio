## 🚀 Cara Menjalankan Proyek Tertentu

1. Clone repository ini:
   ```bash
   git clone https://github.com/maulanaraa/Data-Analysis-Portfolio.git
   cd Data-Analysis-Portfolio
   ```
2. Masuk ke folder proyek yang ingin dijalankan, contoh:
   ```bash
   cd 01_Executive_Superstore_Dashboard
   ```
3. Install dependensi & jalankan:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
